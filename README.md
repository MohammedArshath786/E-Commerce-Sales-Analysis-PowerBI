# E-Commerce Sales Analysis Dashboard

## Overview
An interactive Power BI dashboard analysing e-commerce sales performance across orders, revenue, units sold, product categories, regions, payment methods and years.

## Business questions
- How much revenue and how many units were sold?
- Which product categories and regions contribute most to sales?
- How do payment methods and yearly trends compare?
- What does delivery performance look like?

## Tools
Power BI Desktop, Power Query, DAX

## Report highlights
- 5,000 orders analysed
- ₹5.11M reported revenue
- 20,224 units sold
- Four DAX measures: revenue, average order value, order volume and delivery performance
- Three-page interactive report with slicers

## Files
- `dashboard.pbix` — Power BI report file

## How to view
1. Install Power BI Desktop.
2. Download `dashboard.pbix`.
3. Open it in Power BI Desktop and interact with the report pages and slicers.
